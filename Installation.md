# Installation
- For both Android/PC and iOS (9.3.6 or lower)


## For Android
1. First, you need to have to be either on Bluestacks 5 (PC) or on Android 4.1-4.4
2. Download "SPYMouse-main.zip"
4. Use ZArchiver to extract the files.
5. After extracting the files, move the "com.spymouse_row" folder to "Android-data" folder.
6. Install the "SPYMouse.apk" folder.
7. Open SPYMouse and you're done.
